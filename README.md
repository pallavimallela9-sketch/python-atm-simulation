# ATM Simulation System

This Python program simulates a basic ATM system with PIN authentication, balance management, deposits, withdrawals, transaction history, and PIN change functionality.

## Features

* PIN-based login
* Three PIN attempts
* Balance checking
* Money deposit
* Money withdrawal
* Insufficient balance validation
* Mini statement
* Transaction history
* PIN change option
* Menu-driven interface

## Technology Used

* Python

## Concepts Used

* Variables
* Lists
* `while` loop
* `if-elif-else`
* String methods
* User input
* Arithmetic operations
* Conditional validation
* Menu-driven programming
